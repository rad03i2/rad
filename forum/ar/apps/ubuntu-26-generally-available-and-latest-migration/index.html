GitHub تطرح Ubuntu 26.04 وتبدأ نقل ubuntu-latest

أصبحت صورة Ubuntu 26.04 لبيئة GitHub Actions متاحة للاستخدام الإنتاجي بعد خروجها من المعاينة العامة. وستبدأ GitHub لاحقًا نقل الوسم ubuntu-latest إلى الإصدار الجديد تدريجيًا.

رضوان عبدالهاديمؤسس ومحرر RDWAN Tech
نُشر: 19 سبتمبر 2026
آخر تحديث: 19 سبتمبر 2026 · 3 دقائق قراءة

الخلاصة

  • صورة Ubuntu 26.04 مدعومة رسميًا في مهام GitHub Actions على معماريتي x64 وarm64.
  • يمكن تشغيل الصورة الجديدة عبر ubuntu-26.04 أو ubuntu-26.04-arm.
  • سينتقل الوسم ubuntu-latest من Ubuntu 24.04 إلى Ubuntu 26.04 بين 19 أكتوبر و19 نوفمبر 2026.
  • قد تتأثر مهام البناء التي تعتمد على أدوات أو حزم أو إصدارات تغيرت أو أزيلت.
  • توصي GitHub باختبار المهام على Ubuntu 26.04 أو تثبيتها مؤقتًا على Ubuntu 24.04.

إتاحة رسمية لبيئة Ubuntu 26.04

أعلنت GitHub أن صورة Ubuntu 26.04 المخصصة لعدّادات GitHub Actions أصبحت متاحة للاستخدام الإنتاجي، بعدما خرجت من مرحلة المعاينة العامة. ويشمل الدعم بيئات التشغيل التي تعتمد على معماريتي x64 وarm64، ما يتيح للمشروعات اختبار مهامها وتشغيلها على الإصدار الأحدث من نظام Ubuntu ضمن خدمات GitHub Actions.

يمثل هذا الإعلان انتقال الصورة من نطاق التجربة إلى بيئة مدعومة للاعتماد عليها في مهام سير العمل الإنتاجية. ولا يعني ذلك أن كل مهمة تعمل على صور Ubuntu السابقة ستنتقل فورًا؛ إذ يرتبط التغيير الأساسي بوسم ubuntu-latest، الذي ستبدأ GitHub تحديثه وفق جدول زمني تدريجي.

طرق تشغيل الصورة الجديدة

يمكن للمستخدمين اختيار Ubuntu 26.04 مباشرة داخل ملف سير العمل باستخدام القيمة runs-on: ubuntu-26.04. أما المهام التي تستهدف بيئة arm64، فيمكن تشغيلها عبر runs-on: ubuntu-26.04-arm. ويمنح هذا التحديد أصحاب المشروعات فرصة تجربة الصورة الجديدة قبل اعتمادها تلقائيًا من خلال الوسم العام.

اختيار اسم الصورة صراحةً يساعد على فصل قرار الاختبار عن قرار الترحيل التلقائي. وبذلك يستطيع الفريق مقارنة نتائج مهامه على Ubuntu 24.04 وUbuntu 26.04، والتحقق من الأدوات والحزم المطلوبة، قبل أن يصل التغيير إلى سير العمل الذي يستخدم ubuntu-latest.

تغيير وسم ubuntu-latest

ستبدأ GitHub نقل وسم ubuntu-latest من Ubuntu 24.04 إلى Ubuntu 26.04 خلال فترة تمتد من 19 أكتوبر إلى 19 نوفمبر 2026. وسيجري هذا الانتقال تدريجيًا، لذلك ستتحول مهام سير العمل التي تستخدم الوسم تلقائيًا إلى صورة Ubuntu 26.04 في أثناء نافذة الترحيل المحددة.

يعني استخدام ubuntu-latest الاعتماد على الإصدار المدعوم الأحدث الذي تحدده GitHub، بدل تثبيت رقم إصدار محدد. ومع بدء الترحيل، قد تتغير بيئة التنفيذ الفعلية للمهمة حتى لو لم يتغير ملف سير العمل نفسه، وهو ما يجعل مراجعة الاعتماد على الإصدارات المثبتة مسبقًا خطوة ضرورية قبل الموعد.

تغييرات الأدوات والحزم قد تؤثر في البناء

توضح GitHub أن Ubuntu 26.04 تتضمن أدوات وإصدارات محدثة، مع إزالة بعض الأدوات أو الإصدارات الموجودة في الصور السابقة. وقد تؤدي هذه الفروقات إلى تعطل مهام تعتمد على إصدار محدد من برنامج أو حزمة مثبتة مسبقًا، أو إلى اختلاف نتائج البناء بين الصورة القديمة والجديدة.

لا تحدد المعلومات المنشورة أن كل المهام ستتأثر، بل تحذر من احتمال ظهور مشكلات في سير العمل المرتبط بمكونات تغيرت بين Ubuntu 24.04 وUbuntu 26.04. لذلك ينبغي فحص ملفات البناء والنصوص التي تستدعي أدوات النظام أو تفترض وجود حزم وإصدارات بعينها، ثم اختبار النتيجة على الصورة الجديدة قبل بدء الترحيل.

خيارات الاستعداد قبل الموعد

توصي GitHub باختبار مهام سير العمل باستخدام ubuntu-26.04 قبل انطلاق الترحيل. ويسمح هذا الاختبار برصد حالات الفشل المرتبطة بتغير الأدوات أو الحزم، ومعالجة الإعدادات اللازمة ضمن المشروع بدل انتظار انتقال المهمة تلقائيًا إلى الإصدار الجديد.

أما الفرق التي لا تريد الانتقال في الوقت الحالي، فيمكنها تثبيت المهام على Ubuntu 24.04 باستخدام runs-on: ubuntu-24.04، وبذلك تبقى على الصورة الحالية بدل الاعتماد على ubuntu-latest. وتشير GitHub إلى توثيق العدّادات المستضافة لديها للحصول على معلومات الصور المتاحة، كما تحيل المستخدمين إلى مستودع runner-images للاطلاع على قائمة البرامج المضمنة أو الإبلاغ عن المشكلات المتعلقة بالصورة.
