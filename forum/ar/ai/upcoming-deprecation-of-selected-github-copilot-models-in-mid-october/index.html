GitHub تعلن إيقاف نماذج Copilot محددة في 19 أكتوبر

أعلنت GitHub أن نماذج محددة من GitHub Copilot ستُحال إلى التقاعد في 19 أكتوبر 2026. ويشمل القرار مختلف تجارب الخدمة، ما يستدعي مراجعة سير العمل والتكاملات قبل الموعد المحدد.

نُشر: 19 سبتمبر 2026
آخر تحديث: 19 سبتمبر 2026 · 4 دقائق قراءة

الخلاصة

  • إيقاف النماذج المحددة مقرر في 19 أكتوبر 2026.
  • يشمل القرار Copilot Chat والتحريرات المضمنة ووضعَي ask وagent وإكمال الشيفرة.
  • توصي GitHub بتحديث سير العمل والتكاملات إلى النماذج المدعومة قبل الموعد.
  • تُفعّل البدائل المقترحة تلقائياً لعملاء Copilot Enterprise وCopilot Business ضمن شروط الإعداد الافتراضي.
  • يمكن لعملاء GitHub Enterprise التواصل مع فريق حساباتهم بشأن الأسئلة أو المخاوف.

موعد الإيقاف ونطاقه

أعلنت GitHub عبر مدونتها الرسمية أنها ستوقف نماذج محددة من GitHub Copilot في 19 أكتوبر 2026. ولم يذكر الإعلان، في المعلومات المتاحة، أسماء النماذج المشمولة بالقرار، لكنه أوضح أن الإيقاف سيطبق على جميع تجارب GitHub Copilot. وتأتي الخطوة ضمن تحديث دورة النماذج المتاحة للمستخدمين والعملاء، مع دعوة واضحة إلى الانتقال إلى البدائل المدعومة قبل حلول الموعد.

ويشمل نطاق التغيير Copilot Chat، والتحريرات المضمنة داخل بيئة العمل، ووضع ask، ووضع agent، إضافة إلى إكمال الشيفرة. وبذلك لا يقتصر أثر الإيقاف على واجهة محادثة واحدة أو طريقة استخدام محددة، بل يمتد إلى مجموعة واسعة من نقاط التفاعل التي يعتمد عليها المستخدمون في كتابة الشيفرة ومراجعتها والعمل مع Copilot.

ما الذي ينبغي على المستخدمين فعله؟

تطلب GitHub من المستخدمين تحديث سير العمل والتكاملات للاستفادة من النماذج المدعومة قبل 19 أكتوبر 2026. ويعني ذلك مراجعة أي إعدادات أو عمليات تعتمد على النماذج التي ستتوقف، ثم اختيار البدائل المتاحة وفق سياسات المؤسسة وطريقة استخدام Copilot المعتمدة لديها. ولا يقدم الإعلان أسماء النماذج البديلة في النص المنشور، لذلك ينبغي الرجوع إلى قائمة النماذج المدعومة في وثائق GitHub عند تنفيذ عملية الانتقال.

كما تشير الشركة إلى أن النموذج البديل، بعد تفعيله، سيظهر للمستخدمين في محدد النماذج داخل Copilot Chat، وذلك في تجارب GitHub Copilot المدعومة. وتوفر هذه الآلية نقطة واضحة لاختيار النموذج من الواجهة، بينما تبقى مسؤولية مراجعة التكاملات وسير العمل الواقعة خارج الاستخدام المباشر للواجهة جزءاً من استعداد كل فريق أو مؤسسة.

كيفية تفعيل البدائل للمؤسسات

وفق الإعلان، تُفعّل البدائل المقترحة تلقائياً لعملاء Copilot Enterprise وCopilot Business عند استخدام إعداد تمكين النماذج الافتراضي. ويرتبط هذا التفعيل بشرطين واضحين: ألا يكون المسؤول قد أوقف الإعداد الافتراضي العام، وألا يكون قد عطّل النموذج المعني صراحة. وبذلك قد يختلف ظهور البدائل بين المؤسسات تبعاً للسياسات التي يطبقها المسؤولون على حسابات Copilot.

أما إذا كانت المؤسسة قد عطّلت الإعداد الافتراضي العام، فتوضح GitHub أن الوصول إلى النماذج البديلة يمكن تفعيله من خلال سياسات النماذج في إعدادات Copilot. وتمنح هذه الخطوة مسؤولي المؤسسات مساراً إدارياً مباشراً للتحكم في النماذج المتاحة، قبل موعد إيقاف النماذج المحددة، بدلاً من انتظار التغيير دون مراجعة الإعدادات.

لا إجراء لإزالة النماذج بعد الإيقاف

تقول GitHub إن المستخدمين لن يحتاجوا إلى اتخاذ إجراء لإزالة النماذج بعد إحالتها إلى التقاعد. ويعني ذلك أن إزالة النماذج المتوقفة ليست مهمة إدارية منفصلة يتعين تنفيذها بعد 19 أكتوبر، فيما يظل الإجراء المطلوب قبل الموعد هو تحديث سير العمل والتكاملات واختيار النماذج المدعومة عند الحاجة.

وتفصل هذه التعليمات بين مرحلتين: الاستعداد المسبق للانتقال، ثم إزالة النماذج المتوقفة بوصفها نتيجة للتغيير الذي ستنفذه GitHub. وعلى المؤسسات التي تدير إعدادات Copilot مركزياً أن تتحقق من سياسات النماذج لديها، خصوصاً إذا كانت قد عطّلت التفعيل الافتراضي العام أو فرضت قيوداً صريحة على نماذج معينة.

دعم عملاء GitHub Enterprise

دعت GitHub عملاء GitHub Enterprise الذين لديهم أسئلة أو مخاوف بشأن الإيقاف إلى التواصل مع فريق الحسابات الخاص بهم. ويقدم الإعلان هذا المسار بوصفه قناة المساعدة المخصصة للعملاء الذين يحتاجون إلى توضيحات مرتبطة ببيئتهم أو بسياساتهم أو بعملية الانتقال إلى النماذج المدعومة.

كما أحالت الشركة إلى وثائق النماذج المدعومة في GitHub للحصول على معلومات إضافية حول الخيارات المتاحة في Copilot. وذكرت أيضاً مجتمع GitHub بوصفه مساحة لمشاركة الملاحظات، إلى جانب نشرتها الدورية الموجهة إلى المطورين، والتي تتناول النصائح والأدلة التقنية وأفضل الممارسات. ولا يغير ذلك من الموعد المعلن: 19 أكتوبر 2026 هو تاريخ إيقاف النماذج المحددة عبر تجارب Copilot المشمولة.
