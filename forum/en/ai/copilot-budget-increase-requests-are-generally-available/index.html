GitHub Makes Copilot Budget Requests Generally Available

GitHub has made Copilot budget increase requests generally available for organizations and enterprises using usage-based billing. The workflow lets members request additional budget when they run out of available AI credits, while authorized owners and billing managers can approve, adjust, or deny those requests from settings.

ر Radwan AbdulhadiFounder and editor, RDWAN Tech
Published: September 17, 2026
Updated: September 17, 2026 · 4 min read

Key points

  • Members can request additional Copilot budget when they reach their AI-credit limit.
  • Requests are routed to the organization or enterprise account that pays for the budget.
  • Authorized owners and billing managers can approve, adjust, or deny pending requests.
  • Approval immediately updates the member’s budget and restores access to AI-credit features.
  • The feature is available with GitHub Copilot Business and Enterprise under usage-based billing.

A new path after Copilot credits run out

GitHub has announced the general availability of a workflow for requesting additional Copilot budget. The change addresses a situation in which a member uses all of the Copilot AI credits available to them and is then blocked from Copilot features that consume credits.

Under the new flow, the member can request more budget at the moment the limit is reached. This removes the need to stop using the affected Copilot features without a formal way to ask for additional allocation. The request is sent to the account responsible for paying for the budget.

The feature does not automatically grant more credits to the member. Instead, it creates a request that an authorized person can review and decide how to handle.

Requests follow the paying account

GitHub says requests are automatically routed according to whether the relevant budget is owned by an organization or an enterprise. Requests made against an organization-owned budget appear in the organization’s settings.

Requests against an enterprise-owned budget appear in the enterprise’s settings. This routing gives the account that funds the budget a central place to review requests, rather than requiring members and administrators to manage the process through a separate channel.

The arrangement also ties the requested increase to the budget structure already used for Copilot. The source does not state that the workflow changes ownership of budgets or the underlying billing arrangement; it provides a request and approval path within those existing account settings.

Owners and billing managers can review requests

Organization owners, enterprise owners, and billing managers can review pending requests in the “Requests from members” area. From there, they can decide whether to approve the request, change the amount, or deny it.

When approving a request, the reviewer sets the new amount and selects “Approve and increase.” GitHub says approval updates the member’s budget to the amount selected by the reviewer. The administrator therefore controls the resulting allocation rather than simply accepting an unspecified increase proposed by the member.

The review process is available without leaving the relevant settings. That allows the person responsible for the paying account to examine pending requests and take action in the same administrative environment used to manage the budget.

Approval restores access immediately

GitHub says that approving a request immediately restores the member’s access to AI credits. This is the main operational effect of the new workflow: once the reviewer approves and sets the revised budget, the member can again use Copilot features that consume those credits.

The immediate restoration applies after approval and budget adjustment. A request that is denied does not provide the additional budget, while a request that is adjusted gives the member the amount selected by the reviewer. The source does not describe a separate waiting period or additional activation step after approval.

By combining member-initiated requests with administrator-controlled approval, the workflow is designed to address usage limits while retaining control over the amount assigned to each member.

Availability for Business and Enterprise plans

The budget increase request feature is available with GitHub Copilot Business and GitHub Copilot Enterprise plans under usage-based billing. GitHub’s announcement specifically identifies those plans and billing model as the scope of the release.

The source does not say that the feature is available on other Copilot plans or billing arrangements. It also does not provide pricing, a default increase amount, eligibility rules beyond the stated plans, or limits on how many requests a member can submit.

GitHub directs administrators to its documentation on managing requests for additional Copilot budget and setting up budgets to control spending on metered products. Those materials cover the administrative workflows associated with the release, while the announcement establishes the feature’s availability and core behavior.
