Gmail Adds ‘Copy Code’ Shortcut for 2FA on Android & iOS

Google is streamlining the two-factor authentication process by adding a convenient shortcut to its mobile email application. This update allows users to copy security codes without needing to open individual emails.

ر Radwan AbdulhadiFounder and editor, RDWAN Tech
Published: September 20, 2026
Updated: September 20, 2026 · 4 min read

Key points

  • A new 'Copy code' button for 2FA is now available in Gmail for Android and iOS.
  • The shortcut appears as a pill-shaped button below the email subject line in the inbox.
  • Tapping the button automatically copies the code to the clipboard for immediate pasting.
  • The feature has been observed working on banking and store-related authentication emails.

Enhancing Mobile Authentication Workflow

Google has announced a highly requested quality-of-life update for its mobile email client. As reported by [9to5Google](https://9to5google.com/2026/09/19/gmail-copy-code/), the latest iteration of [Gmail](https://9to5google.com/guides/gmail/) now features a dedicated 'Copy code' button specifically designed for two-factor authentication (2FA). This update follows closely on the heels of other major platform improvements, including the recent launch of [Google rolling out Gmail Live, Docs Live, and Keep Live](https://9to5google.com/2026/09/03/gmail-docs-keep-live/).

Traditionally, when a user receives a 2FA code via email, they must open the message, manually select the numeric sequence, copy it, and then switch back to the application requiring the verification. This process is prone to friction and often slows down the login experience. The new implementation effectively eliminates these steps by providing a direct action from the main interface.

Technical Implementation and Availability

The new feature manifests as a pill-shaped button labeled 'Copy code' followed by the specific numeric string. This UI element is positioned directly beneath the subject line of the email in the user's inbox, behaving similarly to existing preview snippets for image attachments or document files. When a user taps the button, the numeric code is instantly copied to the system clipboard, facilitating a seamless 'paste' action into the target application or website requiring the verification.

According to the latest [Apps & Updates](https://9to5google.com/feature/apps-updates/) logs, the feature is rolling out to specific software versions. On Android, the functionality requires version 2026.09.07.x, while iOS users need to be running version 6.0.260907. It is important to note that, at the time of writing, this specific shortcut functionality remains exclusive to mobile environments and is not currently available on the Gmail web interface.

Broader Context of Workspace Improvements

This update is part of a broader push by Google to integrate its various service ecosystems more tightly. Over the past year, the company has heavily focused on user-centric design refinements to improve the utility of its apps. This includes significant changes such as [Google on why it redesigned the Gmail and Workspace icons](https://9to5google.com/2026/05/26/google-workspace-icons-redesign/), which aimed to unify the visual language across the suite of products. The focus remains on reducing the time users spend inside individual emails when the core information they need is simple.

The integration of smart actions within the inbox is not entirely new for the platform. Similar context-aware features have previously been deployed, such as the [Google Wallet on Android rolling out order tracking dashboard using Gmail](https://9to5google.com/2026/07/02/google-wallet-order-tracking/), which pulls delivery information directly from emails into the digital wallet application. By extracting key data points—whether they are tracking numbers or 2FA codes—Google is transforming the inbox from a static repository of messages into a dynamic, action-oriented hub.

Future Outlook for Notification Integration

While the in-app experience has been significantly improved, many power users are already looking toward the next logical step: notification-based actions. Currently, when an email arrives, users often view the code via a notification shade or lock screen. The ability to trigger the 'Copy code' function directly from a notification would represent another substantial increase in efficiency, effectively bypassing the need to open the app entirely.

As testing continues across various platforms, the feedback from users suggests that this is a highly welcome addition. Banking institutions and e-commerce platforms, which frequently utilize email-based 2FA, have shown consistent compatibility with the feature in preliminary testing. As this feature gains more widespread availability, it is expected to become a standard expectation for mobile email productivity. For further insights on how these changes fit into the broader development cycle, users can follow updates from reporters like [Abner Li](https://9to5google.com/author/technacity/).
