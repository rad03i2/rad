Smart File Manager

Smart File Manager هو مشروع لإدارة الملفات على Windows يركز على المهام التي تتكرر كثيرًا مثل إعادة التسمية الجماعية، معاينة النتائج قبل التنفيذ، وتنظيم الملفات مع فحص التكرار. بُني المشروع باستخدام C# وWinUI 3 و.NET بهدف تقديم واجهة حديثة وسريعة بدل الاعتماد على سكربتات متفرقة أو خطوات يدوية طويلة.

A Windows file-management utility built with C#, WinUI 3 and .NET for batch renaming, file previews and duplicate detection, designed around a clear desktop workflow.

عن المشروع

الفكرة الأساسية للمشروع هي جعل عمليات إدارة الملفات الجماعية أوضح وأكثر أمانًا. بدل تعديل عشرات الأسماء يدويًا، يستطيع المستخدم تحديد مجموعة ملفات، اختيار قاعدة التسمية المناسبة، مراجعة الشكل المتوقع للأسماء ثم تنفيذ التغيير. هذا الأسلوب يقلل الأخطاء ويساعد على التعامل مع المجلدات الكبيرة بصورة أكثر تنظيمًا.

يتضمن اتجاه المشروع أيضًا اكتشاف الملفات المتكررة باستخدام معايير عملية، مع فصل مرحلة الفحص عن مرحلة الحذف أو التعديل. الهدف هو أن يرى المستخدم ما سيحدث قبل تنفيذ أي عملية مؤثرة على ملفاته. هذا النوع من التصميم مهم خصوصًا في أدوات سطح المكتب التي تتعامل مباشرة مع بيانات المستخدم.

المشروع التالي
FEATURE

إعادة تسمية جماعية

معالجة عدد كبير من الملفات وفق نمط تسمية منظم بدل تعديل كل ملف منفردًا، مع تصميم يسمح بتوسعة القواعد والخيارات مستقبلًا.

SAFETY

المعاينة قبل التنفيذ

عرض النتيجة المتوقعة قبل تغيير الأسماء فعليًا، وهي خطوة مهمة لتقليل الأخطاء في العمليات الجماعية والحفاظ على وضوح ما سيحدث للملفات.

DUPLICATES

فحص الملفات المتكررة

تجميع وفحص الملفات التي قد تكون متكررة لتسهيل مراجعتها قبل اتخاذ أي إجراء، بدل الحذف المباشر أو الاعتماد على اسم الملف وحده.

DESKTOP UX

واجهة Windows حديثة

استخدام WinUI 3 لتقديم تجربة سطح مكتب أقرب إلى تطبيقات Windows الحديثة، مع فصل واضح بين اختيار الملفات، إعداد العملية، المراجعة والتنفيذ.

WHY IT MATTERS

لماذا هذا المشروع مهم؟

إدارة الملفات تبدو مهمة بسيطة، لكنها تتحول سريعًا إلى مشكلة عندما يكون العدد كبيرًا أو توجد قواعد تسمية متعددة. المشروع يختصر الوقت ويجعل العمليات الجماعية قابلة للمراجعة بدل تنفيذها بصورة عمياء.
