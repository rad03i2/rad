كيف يجمع Robotics Language Lab عدة لغات في مختبر واحد؟

المستودع لا يحاول أن يكون نظام روبوت كاملًا؛ بل يجمع أمثلة صغيرة ومنظمة لفهم كيف تتقاطع البرمجة المضمنة، التحكم، الملاحة، الوصف الروبوتي والـtelemetry.

Robotics Language Lab مشروع تعليمي متعدد اللغات. الفكرة الأساسية هي أن بيئة الروبوت لا تعتمد عادة على لغة واحدة فقط: قد يوجد firmware قريب من العتاد، خوارزميات تحكم وملاحة، أدوات تشخيص، ملف وصف للروبوت، وخادم أو dashboard للبيانات. لذلك جُمعت أمثلة صغيرة لكل طبقة ضمن هيكل واحد.

1. طبقة الحساسات والتحكم

المستودع يحتوي أمثلة في Python وC وArduino وMicroPython، مع موضوعات مثل PID، ترشيح قراءات الحساسات، والحلقات الشبيهة بما يُستخدم في الأنظمة المضمنة. الهدف هنا هو إبقاء المثال قصيرًا وواضحًا حتى يمكن قراءة المنطق نفسه بدل الاختباء خلف إطار عمل كبير.

2. الملاحة والتخطيط

توجد أمثلة C++ وPython مرتبطة بالتحكم والملاحة، ومنها تخطيط مسار A*. فصل الملاحة عن بقية الأجزاء يساعد على اختبار الخوارزمية ببيانات بسيطة قبل ربطها بحساسات أو محركات فعلية.

3. ROS 2 وURDF كهيكل تنظيمي

المستودع يتضمن بنية تشبه حزم ROS 2 وملفات launch/config وURDF. هذا لا يعني أن المشروع يدّعي توفير stack روبوت متكامل، وإنما يوضح كيف تبدو الملفات التي تصف الروبوت أو تنظم إعداداته ومكوناته ضمن مشروع أكبر.

4. Telemetry والتشخيص

طبقة أخرى تعرض نقل وعرض البيانات: مثال خادم telemetry بلغة Go، dashboard في JavaScript، parser في TypeScript، وأداة تشخيص C#. وجود هذه الأمثلة يوضح أن بيانات الروبوت قد تنتقل من البرنامج المضمن إلى خدمة أو واجهة مراقبة مكتوبة بلغة مختلفة تمامًا.

5. لماذا مستودع واحد؟

الفائدة من التنظيم المشترك هي رؤية الحدود بين المسؤوليات: firmware لا يحتاج أن يعرف كيف تُرسم الواجهة، والـdashboard لا يحتاج أن ينفذ خوارزمية التحكم بالمحرك. كل مثال صغير، لكن الخريطة العامة توضح كيف يمكن للغات المختلفة أن تتعاون.

المستودع موصوف صراحةً كمختبر تعليمي، وليس كمنصة إنتاجية أو نظام تحكم لروبوت تجاري.

6. أمثلة تشغيل منشورة

  • python python/control/pid_controller.py لتجربة PID.
  • python python/navigation/a_star.py لتجربة A*.
  • go run go/telemetry-server/main.go لخادم telemetry.
  • dotnet run --project csharp/RobotDiagnostics لتشخيص C#.
